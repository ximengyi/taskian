# Taskian 0.4.1

0.4.1 是 0.4 的交互与登录修复版本。

## 修复

- 修复个人模式下普通微信消息被静默忽略的问题。没有 Agent 正在等待回答时，普通文本现在会直接创建默认 Agent 任务；未选择项目时以当前用户主目录作为“全局”工作目录。
- 修复 Windows 终端二维码黑白模块方向错误及字符渲染不稳定的问题。终端二维码改用 `mdp/qrterminal` 渲染，并保留足够静区。
- 登录二维码 PNG 提升到 768 像素和高纠错级别；Windows 会自动打开图片，方便直接扫码。

## 新增

- 支持通过微信请求关机或重启。
- 系统操作采用两步确认：Taskian 返回 2 分钟有效的一次性确认码，只有收到匹配的 `#confirm <确认码>` 后才执行。
- Windows 确认后延迟 30 秒执行，Linux/macOS 延迟 1 分钟执行；可用 `#confirm cancel` 取消确认请求。

## 安全说明

- 自然语言关机请求本身不会直接关机，也不会发送给 Codex/Cursor 执行。
- 不匹配或过期的确认码不会执行系统操作。
- 升级后台服务后需要重启 Taskian，正在运行的 0.4 进程不会自动加载新代码。
