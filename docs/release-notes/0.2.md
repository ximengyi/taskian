# Taskian 0.2

Taskian 0.2 将 0.1 的单次文件任务转发器升级为可在纯命令行服务器运行的双向编程 Agent 调度器。

## 新功能

- 直接连接腾讯 iLink，并通过 `taskian ilink login` 在终端显示微信登录二维码。
- Codex 原生 `thread_id` 持久化和 resume。
- Cursor 原生 `session_id` 持久化和 `--resume`。
- Agent 可以暂停提问；用户通过 `#reply <任务号>` 恢复同一会话。
- 新增 `#status`、`#cancel` 和 `#help` 微信命令。
- 使用 SQLite 保存任务、用户可见消息、会话 ID、iLink cursor 和消息去重状态。
- 支持最多多个并发 Agent 任务，等待回答的任务不占用执行槽。
- 新增 `taskian status`、`taskian ilink status` 和 `taskian ilink logout`。
- 保留 Wechatian/Obsidian 文件通道，并支持导入 0.1 消息去重状态。

## 安全与可靠性

- 默认只接受扫码绑定用户，可额外设置 `allowed_senders`。
- Agent 和项目使用本地白名单，微信正文不经过 shell。
- Codex 默认保持 `workspace-write` 沙箱；Cursor 不默认启用 `--force`。
- Taskian 重启后保留等待回答任务；被中断的运行任务不会自动重复执行。
- iLink Token 使用独立权限文件保存，日志不输出 Token。
- iLink 网络断开后继续长轮询；重复消息不会重复创建或恢复任务。

## 升级说明

1. 备份原来的 `~/.taskian` 目录。
2. 使用新的平台二进制替换 0.1。
3. 参考新的 `config.<平台>.example.json` 增加 `database_path`、`channel`、Agent `type` 和项目 `allowed_agents`。
4. 运行 `taskian ilink login` 完成扫码绑定。
5. 运行 `taskian check`，确认 Agent 命令和项目路径可用。
6. 重启 Taskian 服务。

0.1 的 `state.json` 会在首次启动时导入 SQLite。需要继续使用 Obsidian/Wechatian 时，可把 `channel.type` 设置为 `wechatian-files`。

## 已知限制

- iLink 通道当前只支持文本和语音转写文本作为命令输入，不传输图片、文件、视频或原始语音。
- Codex/Cursor 的原生会话必须保留在同一操作系统用户的 Agent 数据目录中。
- Taskian 进程意外退出时，无法安全接管仍在运行的孤儿 Agent 进程；相关任务会标记为 `resume_failed`。
- 腾讯 iLink 接口属于外部依赖，接口或服务规则变化可能需要更新 Taskian。
