# Taskian 0.3

这个版本让 Taskian 可以长期无人值守运行，不再要求每次启动前手动执行 `taskian check`。

## 新功能

- `taskian serve` 启动时自动检查 Codex/Cursor 登录状态和项目目录。
- 默认每 5 分钟执行健康检查，并在故障或恢复时通过 iLink 提醒。
- 新增 `taskian agents detect`（支持 `-json`），自动查找 PATH 和常见安装目录中的 Agent CLI。
- 配置命令失效时，Taskian 会自动使用探测到的同类型 CLI。
- 单个 Agent 故障不会影响其他 Agent 和微信消息通道继续运行。

## 升级说明

0.2 配置可以直接使用。健康检查默认开启；如需修改：

```json
"health": {
  "enabled": true,
  "interval": "5m"
}
```

iLink 会默认提醒扫码绑定用户。文件通道需要通过 `health.notify_senders` 指定接收者，或从服务日志查看状态。

健康检查只调用 Agent CLI 的登录状态命令，不发起模型任务，因此不消耗模型 token。

## 已知限制

- 自定义安装位置可能需要把 Agent 加入 PATH，或在配置中填写绝对路径。
- 登录状态正常不代表网络、额度和服务端在真实任务执行时一定可用。
