# Taskian 0.4

0.4 将 Taskian 升级为适合个人使用的全局 Agent 调度器，并补齐首次安装与后台运行体验。

## 新功能

- 无参数运行进入初始化向导，自动创建个人模式配置、探测 Codex/Cursor 并打印 iLink 二维码。
- Windows 可直接双击程序；扫码后选择默认的 `Y`，Taskian 会安装到稳定目录、创建当前用户计划任务并转入后台。
- Linux 自动安装和管理 systemd user service，并在未启用 linger 时提示处理方法。
- 新增统一的 `taskian service install/start/stop/restart/status/logs/uninstall` 命令。
- 新增跨平台单实例锁，防止前台和后台同时长轮询同一个 iLink 身份。
- 新增个人模式：无需预先维护项目白名单或 Agent 列表，Codex/Cursor 在运行时自动发现。
- 支持直接使用绝对目录，或通过 `#project add` 注册项目名称；项目注册和当前项目保存在 SQLite。
- 新增 `#project list/show/rename/remove/find` 和 `#use`。
- 新增默认 Agent；`#task` 使用默认值，`#codex`、`#cursor` 可显式切换。
- 微信发送 `help`、`#help`、`帮助` 或分类帮助即可查看可用命令和当前上下文。
- Windows 后台日志写入用户数据目录并进行简单轮转；Linux 日志通过 user journal 查看。

## 兼容性

- 0.3 的受控模式配置继续支持；带有预配置项目的旧配置会保持严格项目限制。
- 个人模式仍受当前操作系统用户权限和 Agent 自身沙箱约束。
- iLink 默认只接受扫码绑定身份，不要求额外填写发送者白名单。

## 使用方式

首次运行：

```text
taskian
```

后台管理：

```text
taskian service status
taskian service logs
taskian service restart
```

微信项目注册与任务：

```text
#project add week-report D:\cursorwork\week-report
#use week-report
#cursor 写一下本周周报
```

## 注意事项

- Linux user service 需要启用 linger 才能在用户完全退出登录后继续运行；Taskian 会检测并给出命令，但不会自行获取 sudo 权限。
- 删除项目别名或卸载后台服务不会删除代码、配置、登录状态、SQLite 或 Agent 会话。
- macOS 继续支持前台运行和跨平台构建，0.4 的自动后台服务管理范围为 Windows 与 Linux。
