# Taskian 0.5

0.5 将 Taskian 升级为微信与飞书同时在线的多通道本地 Agent 调度器，并让频繁切换项目的聊天操作更直接。

## 新增飞书通道

- 同一个 Taskian 进程可同时连接腾讯 iLink 和飞书，任务结果返回原消息通道。
- 飞书基于官方 Go Channel SDK 使用 WebSocket 长连接，不需要公网回调地址。
- `taskian feishu setup` 支持官方设备授权自动配置；企业环境也可通过 `-manual -app-id -app-secret` 使用已有自建应用。
- 手工配置使用 10 分钟一次性绑定码确定本机所有者；未绑定用户和非所有者无法调度 Agent。
- 群聊默认必须 @机器人，私聊可直接发送文本；0.5 对图片和附件给出明确的不支持提示。
- 多通道独立轮询、重连和错误隔离；一个通道故障不会阻塞另一个通道。

## 全局当前项目

- 项目表升级为稳定自增数字 ID，旧 0.4 项目首次启动时自动事务化迁移。
- 个人模式新增唯一的全局当前项目，微信和飞书共享，程序重启后继续生效。
- 支持自然语言 `当前项目`、`项目列表`、`切换项目 <ID或名称>`。
- 发送项目列表后的 5 分钟内可直接回复数字 ID 切换；有 Agent 等待回答时仍优先把纯数字作为任务回答。
- 普通文本、`#task`、`#codex` 和 `#cursor` 在未显式指定项目时统一使用当前项目。
- 新增 `修改项目路径 <ID或名称> <绝对路径>` 与 `#project path`；新任务立即采用更新后的目录。
- 当前项目不可直接删除，避免无意清空全局工作上下文。

## 兼容与迁移

- 旧版单个 `channel` 配置继续可用；增加飞书时自动升级为 `channels` 数组。
- 任务新增 `project_id`，升级时会按旧项目名称回填，同时保留项目名称与执行时路径作为历史快照。
- 0.4 的 iLink 登录、Wechatian 文件通道、Agent 会话恢复、任务命令与项目名称用法保持兼容。

## 本地验证

- 单元测试覆盖 0.4 项目表迁移、稳定 ID、选择上下文过期、跨通道全局切换、飞书绑定码以及消息回程路由。
- 通过 `go test ./...` 和 `go vet ./...`。
- 发布产物包括 Windows amd64、Linux amd64、macOS amd64 与 macOS arm64。

完整设计和验收标准见 [`docs/0.5.md`](../0.5.md)。
