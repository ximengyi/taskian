# Taskian 0.4.2

0.4.2 修复全局目录中的 Codex 任务启动失败，并补齐可观察性。

## 修复

- Codex 在非 Git 工作目录中自动使用 `--skip-git-repo-check`。个人模式默认的“全局”目录现在可以正常启动 Codex。
- 将“关一下机”纳入关机口语识别，进入一次性确认码流程，不再作为普通 Agent 任务。
- Agent 失败时保留并返回原始诊断信息，不再只报告 `exit status 1`。

## 日志

- Windows CMD 实时显示收到的微信消息、任务号、Agent、项目路径和执行阶段。
- Codex、Cursor 和通用 CLI 的标准输出与错误输出会实时显示，并带有 Taskian 任务号。
- 任务等待回答、完成和失败均有明确日志；后台服务同步写入 `~/.taskian/logs/taskian.log`。
- 日志不打印 iLink 凭据或 Agent 环境变量，但会记录用户主动发送的任务内容，便于本机排错。
